# Entries are sorted by key

Entries are sorted by `logic_ref ‖ label_ref`, the order in which arm-risc0 sorts the leaves of the kind table's Merkle tree. The file order does not change the commitment, but the sort makes the table a function of the entry set: two branches adding tokens merge to one table, and "same entries, different files" is unrepresentable. Position in the table does not matter to the circuit, which reads one Merkle path per resource, so nothing argues for any other order; human grouping lives in `_metadata` objects, which the generator carries through and the hash ignores.
